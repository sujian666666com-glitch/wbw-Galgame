# 新增剧情与扩写规则

## 目标

在不破坏现有六章主线、人物设定、9 组选项和 3 个结局的前提下，补充必要过场、人物互动和场景衔接，使剧情可稳定映射为 Ren'Py 流程。

## 当前剧情基线

- 主角王不稳的核心动机是“三个月，留下来”。
- 许晚晴欣赏的是王不稳的清醒、执行力和不认命，而不是单纯安慰或无条件支持。
- 主线顺序为：初到城市、第一次反打、并肩合作、被打压、正式翻盘、最终选择。
- 选择 1 至选择 8 调整许晚晴好感度；选择 9 决定稳定、上升、创业三个结局。
- 当前原稿逐项计算后的理论最高好感度为 27；原稿附录中的 32 属于计算错误。实现时不得把“满分 100”误当作现有剧情可达到的分数。

## 新增规则

### 1. 不改变既有主线因果

- 新增剧情只能补充动机、过渡、关系变化或选择反馈，不得让王不稳依赖偶然贵人直接解决核心矛盾。
- 不得提前消解“功劳被抢”“正式翻盘”“三选一结局”等关键冲突。
- 如确需改变既有选择、好感度或结局条件，应先更新剧情文档与任务清单，再进入实现。

### 2. 保持人物一致

- 王不稳：冷静、要强、重视证据与行动；可以犹豫，但不以无意义抱怨推动剧情。
- 许晚晴：清醒、有判断力、能独立行动；不得降格为只提供情绪价值或只围绕王不稳行动的角色。
- 王磊与张浩：行为应服务职场冲突，避免无铺垫的极端反派化。
- 新角色必须有明确剧情功能，不为填充时长随意加入。

### 3. 控制新增内容边界

- 优先复用现有场景与角色表情；新增背景或立绘需求必须登记到素材盘点或任务清单。
- 每段新增剧情应说明：插入位置、剧情目的、涉及角色、场景素材、是否含选择、对变量的影响、返回主线的位置。
- 新增选择必须产生可感知差异，至少影响对话反馈、好感度、后续回调或结局条件之一。
- 不新增无法在当前项目范围内兑现的复杂系统，例如养成、自由地图、联网服务或高成本小游戏。

### 4. 好感度与分支规则

- 使用单一、可追踪的许晚晴好感度变量，所有加减值与原稿一致。
- 普通扩写默认不修改好感度；需要修改时必须在剧情文档中写明数值与理由。
- 分支结束后应回收至明确主线节点，避免产生无法继续或无法到达结局的死分支。
- 三个结局必须都可从新存档正常到达，不把任何结局锁定在未说明的隐藏条件后。

### 5. 文本与演出规则

- 对话与旁白使用简体中文，保留必要英文词汇，如 offer、AA。
- 角色名、变量名、标签名和素材引用保持一致，避免同一概念多种写法。
- 每个场景进入时明确背景、时间与角色状态；场景结束时明确转场或返回点。
- 重要选择前后保留存档与回滚可用性，不在选项展示阶段执行不可逆副作用。
- 中文引号、标点、换行和长文本需在目标字体下实际检查。

## 验收标准

- 不改变既有主线关键因果与三个结局的基本含义。
- 新增人物行为符合设定，且有明确剧情功能。
- 所有新增选择、变量变化和回收节点可追踪。
- 所需素材已登记，缺失素材有明确替代或补充任务。
- 新增剧情完成 Ren'Py lint、主线通读和相关分支测试后，才能标记为已验收。

## 第一版已登记补充

### ADD-01：金钱与生活压力

- 状态：已验收
- 插入位置：第一章房租、第三章咖啡与 AA 吃饭、第五章项目奖金。
- 剧情目的：让“身上只有 2300 元”形成可感知约束，并为创业结局资源条件提供依据。
- 变量影响：房租 `-1200`；咖啡 `-18`；AA 吃饭 `-50`；救场奖金 `+800`。
- 返回主线节点：各事件结束后直接回收至当前章节主线。

### ADD-02：能力、证据与创业伏笔

- 状态：已验收
- 插入位置：第一至第五章的职业相关选择与项目事件。
- 剧情目的：将王不稳的执行力、证据意识和并肩合作转化为可追踪状态。
- 变量影响：职业选择提高 `ability`；数据验证与工作记录设置 `evidence_ready`；小爆款合作设置 `side_project_ready`。
- 返回主线节点：不改变原六章顺序。

### ADD-03：三结局普通与理想表现

- 状态：已验收
- 插入位置：第六章最终选择之后。
- 剧情目的：保持三个结局始终可选，同时让此前选择改变关系表达、资源准备和未来预期。
- 理想条件：稳定为 `ability >= 7` 且 `affection >= 15`；上升为 `ability >= 9` 且 `affection >= 12`；创业为 `ability >= 8`、`affection >= 15`、`money >= 1800` 且已有创业伏笔。
- 普通表现：未达到理想条件时仍进入对应主结局，但表达更克制。

### ADD-04：活动主视觉合影 CG

- 状态：进行中（已完成静态引用检查，待 Ren'Py SDK lint/test）
- 插入位置：第三章“小爆款”早会表扬之后、早会后回应选择之前。
- 剧情目的：将用户提供的四人客厅合影作为新品推广活动主视觉成片加入游戏，强化“策划创意 + 数据判断”共同推动活动成功的表现。
- 涉及角色：王不稳、许晚晴；图中四位女孩作为活动主视觉模特/画面内容出现，不新增独立剧情分支。
