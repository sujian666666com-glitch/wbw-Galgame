# 樱镜町续篇：完整故事大纲

## 作品定位

《樱镜町》是《三个月，留下来》的平行世界续篇。主角仍是王不稳，时间位于旧篇结局约两年后。

续篇保留旧篇“选择、执行、为结果负责”的人格核心，但把问题从“如何在一座城市留下来”推进为：

> 当一个世界要求少数人用遗忘换取所有人留下时，能否让知情、自愿、可撤回的共同承担代替牺牲？

四季镜不是具有人格的反派。它是樱镜町建立之初用于稳定平行世界的应急装置，长期执行“以最少承载者维持最多生命”的旧规则。冲突来自被简化的历史、集中承担的制度和每个人对失去的恐惧。

## 人物与成年设定

| 角色 | 身份与年龄 | 季节 | 性格与独立目标 |
|---|---|---|---|
| 王不稳 | 22 岁，旧篇结束两年后的主角 | 外来见证者 | 保留旧篇全部记忆与证据意识；先观察、核对，再行动。他最初想弄清回去的方法，最终必须决定如何承担两个世界的责任 |
| Dana | 樱镜学园大学部一年级成年学生，王不稳的邻居 | 春 | 活泼但并不幼稚，记得旧街每位居民。她希望人与人重新建立联系，不再把记住所有人当成自己的个人义务 |
| Luna | 樱镜学园大学部学生、学生会学籍协查负责人 | 夏 | 冷静、精确，长期离线保存被改写的数据。她希望事实成为任何人都能复核的公共记录，而非少数人的权威 |
| Irene | 24 岁，大学部档案馆助理、前学生会长 | 秋 | 成熟克制，十二岁时曾是秋之承载者。她希望保护小镇，却因创伤把真相锁了十二年，最终学习让保护与知情同意并存 |
| Ruby | 樱镜学园大学部成年学生 | 冬 | 温柔忧郁，能从耳坠中听见被删去的名字。她希望以 Ruby 本人的身份留下，而不是继续成为“冬之女”或任何人的代价 |

樱镜学园是包含大学部的综合学院。大学部学生均为成年人，只在典礼或学生会值勤时穿统一制服，因此王不稳 22 岁进入学园与现有角色外观不冲突。

## 与旧篇的连接方式

旧篇三个结局都会写入持久状态，续篇入口读取最近完成的结局；没有旧篇记录时使用 `unknown` 中性回顾。

| `sequel_origin_ending` | 两年经历的回顾重点 |
|---|---|
| `stable` | 王不稳留在最初的公司，从实习生成长为能够独立负责项目的人 |
| `rising` | 王不稳进入更大的城市与平台，在更快节奏中继续向上 |
| `startup` | 王不稳持续迭代自己的产品，为每次成败直接负责 |
| `unknown` | 不指定旧篇选择，只概括他已经学会承担自己作出的决定 |

四种回顾只改变文本，不锁定续篇角色路线或结局。

## 世界设定闭环

### 镜生成的身份

王不稳在樱镜町车站醒来时，身边多出一只陌生行李箱。箱内包含：

- 合身衣物与旧宅钥匙；
- 樱镜学园大学部录取通知、租约和学籍回执；
- 提前三个月签发的完整身份材料；
- 预先缓存车站至旧宅区路线的离线地图。

手机没有网络，但离线地图可以正常使用。三份材料上的签名像王不稳的字，却在收笔位置保留同一个模仿错误。

冬章揭示：四季镜从王不稳的记忆读取名字、年龄和笔迹，为了让外来见证者能够在本世界停留，直接补写了行李、住处和学籍。镜能复制结果，却不能理解他写字时最后一下停顿，因此留下可验证的破绽。

### 银白光与四季镜

十二年前，Irene 经历过上一轮四季失衡，并被集中选为秋之承载者。现在新的循环开始，Ruby 首先面临从照片、学籍与他人记忆中消失。

Dana、Luna、Irene、Ruby 对“不想再有人被独自牺牲”的无意识愿望通过冬之钥印进入镜。四季镜一面执行求救，一面寻找不受本世界改写的外来承载者，于是银白光把王不稳带到樱镜町。

它不是某人布置的陷阱，也没有预先选定爱情对象。

## 八段剧情结构

## 第一段：穿越序章《消失的街头》

对应 label：`sequel_prologue`

### 关键节拍

1. 根据旧篇持久结局展示稳定、上升、创业或未知四种回顾。
2. 两年后的雨夜，王不稳在城市街头发现银白异常。
3. 春花、夏潮、秋叶、冬雪同时出现，街道被镜面般的光吞没。
4. 他在樱镜町车站醒来，发现陌生行李、大学部材料、旧宅钥匙和离线地图。
5. 玩家可选择系统核对文件；理想选择取得第一点洞察。
6. Ruby 在雨中出现，为他指路。她看见冬纹，也提前知道他的名字，却暂时没有解释。

### 选择意义

- “逐项核对文件、日期和签名”体现王不稳的证据习惯，`sequel_insight +1`。
- “先确认住处”仍能继续主线，但不会获得洞察。

### 回收点

Ruby 离开后，王不稳决定先验证镜替他写好的身份，再调查 Ruby 为什么认识自己，进入初遇章。

### 主要演出

- `bg city_anomaly`
- `bg sakurakagami_station_rain`
- `ruby normal`
- `wangbuwen normal`

## 第二段：初遇《被写好的身份》

对应 label：`sequel_chapter_01`

### 关键节拍

1. 旧宅钥匙能够开门，屋内物资也被提前准备，证明生成身份不只存在于纸面。
2. Dana 以邻居和大学部学生身份带王不稳去报到。
3. Luna 查到学籍恰好在三个月前生成，录入账号不存在，纸质和电子签名保留同一处错误。
4. Ruby 在校园认出“昨晚车站的人”，完成两次见面的明确回调。
5. 王不稳可选择向 Ruby 和其他人坦白银光、陌生行李与伪造身份。
6. Irene 以 24 岁大学部档案馆助理、前学生会长身份登场，说明旧纹章十二年没有用于正式文件。
7. 四人的饰物和设备分别出现春、夏、秋、冬反应，王不稳确认它们与穿越时的四季重叠一致。

### 选择意义

- 坦白真实来历：`ruby_affection +1`、`sequel_resolve +1`。
- 暂时沿用转学生身份：不加数值，Ruby 保持距离。
- 立即核对学籍时间、账号和签名：`sequel_insight +1`。
- 先完成报到：不加数值，但 Luna 仍离线保存原始记录，主线不中断。

### 回收点

Dana 提议去春庭参加居民复兴活动；Luna 确认春庭已有异常生长记录，众人共同前往。

### 关键 CG

`cg sequel_four_meeting`：四位女孩在学院庭院首次同场，四季光短暂交汇。

## 第三段：春之章《一夜盛开的庭院》

对应 label：`sequel_chapter_02_spring`

### Dana 的主动目标

Dana 主动发起春庭复兴活动，花一周整理名单、三天逐户邀请居民。她希望旧街居民重新说上话，而不是等待主角替她解决孤独。

### 关键节拍

1. 花朵在一分钟内萌芽、盛开、枯萎。
2. 现场名单有二十七人，实际只剩二十六人；大家看得见遗留手套，却忘记它的主人。
3. Dana 能记得被抹去者留下的情绪，无法想起名字。
4. 她组织每位见证者说出一段残留细节，让零碎记忆重新组成一个真实存在过的人。
5. 共同保存记忆后，春之碎片出现。

### 两次核心选择

1. 先问 Dana 需要什么，再按她的方案分工：`dana_affection +2`。接管或单纯解散活动不加数值，Dana 仍会坚持自己的判断。
2. 让每位见证者各保存一小段并互相核对：`dana_affection +1`、`sequel_insight +1`、`sequel_resolve +1`。把全部记录集中给 Dana 或王不稳不会加数值，Dana 会主动改为分布保存。

### 回收点

`spring_fragment = True`。Luna 将春庭数据与海岸记录比对，发现海灯祭试运行当晚可能出现逆流潮汐。

### 关键 CG

`cg sequel_dana_spring`：Dana 在枯萎春庭中央举起陌生手套，居民逐一补回记忆。

## 第四段：夏之章《逆流的海灯》

对应 label：`sequel_chapter_03_summer`

### Luna 的主动目标

Luna 已经长期测试数据被改写的速度。她希望异常成为所有人可以交叉验证的公共事实，而不是依赖某个聪明人或权威的结论。

### 关键节拍

1. Luna 制定海灯祭疏散与三个观测点的安全方案。
2. 海浪停止，整片海违反重力向灯塔倒流。
3. 电子设备开始自动覆盖旧数据，只有原始纸带和分散副本保留异常。
4. Irene 从灯塔档案找到十二年前同样的潮汐曲线，以及被刮去姓名的“夏季承载完成”记录。
5. 众人开始怀疑所谓承载并非唯一方案。

### 两次核心选择

1. 执行 Luna 的分组方案并带回纸带：`luna_affection +2`、`sequel_insight +1`。擅自离开安全绳或放弃数据不会加数值，但不会造成死亡分支。
2. 公开可复核证据并邀请见证者补充：`luna_affection +1`、`sequel_resolve +1`。直接倾倒原始资料或封锁消息不会加数值，Luna 最终仍会选择负责任的分布公开。

### 回收点

`summer_fragment = True`。十二年前的日志指向 Irene 的旧权限账号，她答应在档案馆公开秋天真正拿走的东西。

### 关键 CG

`cg sequel_luna_tide`：Luna 在逆流海潮与夏夜灯塔前保存即将被覆盖的原始日志。

## 第五段：秋之章《红蔷薇的旧档案》

对应 label：`sequel_chapter_04_autumn`

### Irene 的主动目标

Irene 十二岁时经历连续三个秋天，并失去关于母亲的一部分记忆。她毕业后留在档案馆，不是为了继续控制学生会，而是为了保存每次改写前的记录。

### 关键节拍

1. Irene 承认删除日志，因为她一直相信知情者越多，镜能索取的记忆越多。
2. 她拿出四季镜创始记录和被撕掉的半页。
3. 镇上传说“四人献出记忆，四季得以轮转”并非完整原文；原句是“四季由众人共同记忆”。
4. 集中牺牲只是方便管理的旧应急方案，经过十二年被误当成不可更改的传统。
5. Irene 想再次独自接过秋印，也借此送王不稳回去。
6. 无论选择如何，她最终主动开放档案，不再把自己设为唯一守门人。

### 两次核心选择

1. 让 Irene 说完并逐页核对：`irene_affection +2`、`sequel_insight +1`。直接指责她不会加数值。
2. 拒绝未经本人和众人同意的牺牲：`irene_affection +1`、`sequel_resolve +1`。接受她独自承担不会加数值，其他三人仍会阻止旧仪式重演。

### 回收点

`autumn_fragment = True`。档案最后一页指出下一位是冬之承载者；众人意识到 Ruby 的名字将在一夜内被镜收回。

### 关键 CG

`cg sequel_irene_archive`：Irene 在红叶与旧档案中拼回被撕掉的创始记录，并向所有人打开档案。

## 第六段：冬之章《被忘记的名字》

对应 label：`sequel_chapter_05_winter`

### Ruby 的主动目标

Ruby 不想作为“冬之女”或他人的代价被保存。她要自己说出名字、表达是否承担，并以一个拥有选择权的人留下。

### 关键节拍

1. 樱镜町一夜入冬，车站时钟停在王不稳穿越的那一分钟。
2. Ruby 从课堂点名、邻居记忆和合影中逐渐消失。
3. 她的耳坠保存被删去的名字，却无法单独保存自己。
4. Ruby 解释银白光、陌生行李、租约、学籍和仿签都来自四季镜的求救与身份补写。
5. Dana 分发姓名卡，Luna 接通全镇广播，Irene 开放旧录音；居民共同念出 Ruby 的名字。
6. 冬之钥印要求一名承载者独自接住冬夜，但 Ruby 明确说出“不想消失，也不想用别人消失换自己留下”。

### 两次核心选择

1. 请 Ruby 亲手写下名字和意愿，让所有人共同读出：`ruby_affection +2`、`sequel_insight +1`。只承诺个人永不忘记不会加数值，因为那仍会把她变成只属于一个人的影子。
2. 尊重 Ruby 的决定，与其他三人共同扶住钥印：`ruby_affection +1`、`sequel_resolve +1`。抢过钥印替她承担不会加数值，她也不会放弃自己的决定权。

### 回收点

`winter_fragment = True`。封闭多年的镜室入口打开，五人沿车站下方阶梯进入终章。

### 关键 CG

`cg sequel_ruby_name`：Ruby 在结霜玻璃上写下姓名，四个人的手共同扶住即将闭合的冬光。

## 第七段：镜室终章《没有人必须被忘记》

对应 label：`sequel_finale`

### 关键节拍

1. 四枚碎片嵌入车站下方的四季镜，春花、夏潮、秋叶、冬雪同时出现。
2. Dana 组织居民姓名卡；Luna 建立十二个独立观测节点；Irene 开放全部档案；Ruby 把耳坠中的声音接入广播。
3. 镜展示三种旧解：四人各失去核心记忆、外来见证者失去原世界、关闭镜让樱镜町停止。
4. Luna 确认镜的目标是以最少承载者维持最多生命，它从未计算知情、自愿、可撤回的分布承担。
5. 王不稳按顺序提交文件、时间戳、潮汐日志、创始记录和姓名卡，提出新协议。
6. 镜根据此前状态显示可执行的六个结局选项。

### 新协议原则

- 记忆负荷不再强制集中；
- 每一份承担必须知情、自愿、可撤回；
- 记录必须由多人保存、能够交叉复核；
- 没有任何角色能替另一人决定是否牺牲。

### 关键 CG

`cg sequel_mirror_finale`：四位女孩围住破裂四季镜，镇民记忆形成分布式光网。

## 第八段：六个结局

### Dana 结局《春日归邻》

显示条件：`dana_affection >= 3`。

王不稳选择成为外来的稳定锚点，旧世界之门永久关闭。Dana 与他把春庭和旧车站改造成新居民互助站，每位新住民都先收到一张邻居姓名卡。Dana 不再独自负责“让所有人留下”，两人一起迎接每一次新相遇。

### Luna 结局《盛夏坐标》

显示条件：`luna_affection >= 3`。

王不稳留下成为稳定锚点。Luna 把灯塔改造成公开观测站，潮汐、温度、记忆偏差与镜波动由居民共同复核。事实不再属于最聪明的个人，两人也拥有共同标记的未来坐标。

### Irene 结局《秋实之书》

显示条件：`irene_affection >= 3`。

王不稳留下成为稳定锚点。Irene 永久开放档案核心区，同时保留个人隐私和拒绝公开的权利。她把新的铜钥匙交给王不稳，两人成为平等而非孤独的守护者。

### Ruby 结局《冬夜来信》

显示条件：`ruby_affection >= 3`。

王不稳留下成为稳定锚点。Ruby 恢复姓名、学籍和照片中的位置，并在旧车站整理被循环抹去者的来信。初雪之夜，两人把名字并排写下，选择不只一个冬天的未来。

### 返回结局《回到灯火》

显示条件：始终显示。

四名承载者共同接管经过修正的本地协议，王不稳带着证据返回旧世界。原世界只过去一秒，并根据 `stable`、`rising`、`startup`、`unknown` 展示不同回调。他保留写满姓名、潮汐和四季的笔记，确认樱镜町不是梦。

### 真结局《四季同在》

显示条件：

- 四名角色信任均不低于 3；
- `sequel_insight >= 6`；
- `sequel_resolve >= 4`；
- 春、夏、秋、冬四枚碎片全部取得。

居民自愿分担记忆负荷，四季镜第一次找到旧规则之外的解。没有人被抹去，也没有人被迫永久留下。镜成为只在四季交界、两边同时邀请时开启的双向门。王不稳先回旧世界完成原有责任，一年后带着自己的行李重返樱镜町。

## 主题落点

旧篇的“留下来”不是占据一座城市的位置；续篇进一步说明，真正的留下是持续对自己作出的选择负责。

樱镜町最终得以存在，不是因为找到更合适的牺牲者，而是因为所有人终于知道真相，并愿意共同保存彼此存在过的证据。
