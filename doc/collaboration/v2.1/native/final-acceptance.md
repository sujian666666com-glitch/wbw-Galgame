# 原生完整游玩最终验收

2026-10-25，主 Agent / 原生 CUA。机器：macOS 26.2、Apple M4、arm64；1920×1080 游戏，2736×1540 窗口 drawable，另检查全屏 2940×1912（等比留边）。

## 方法与证据边界

四条路线均从主菜单开始，使用真实点击、游戏自带快进、保存和读取；不跳 label，不用控制台设置数值。普通对白部分使用快进，关系转折、新增场景、结局与低信任台词停下来检查；被动 observer 只记录真实进入的 label、对白与状态，不修改游戏。完整记录见 `playthrough.jsonl`，汇总和事件索引见 `acceptance-evidence.json`。这不是四遍逐字慢速朗读，也不冒称每个选项均由主 Agent 手点：全部 61 项由自动化覆盖，原生验证四条贯穿路线与全部结局。

早期 SDK 正常模式验证旧篇，后续在独立 `.app` 中验证续篇与最终 UI。两个较长手动会话达到最初 1800 秒监管上限后被正常回收，续篇从自然自动存档恢复，没有跳过故事；最后会话正常退出。最终另做完全无 observer 的干净包复查，见 `clean-package-smoke.md`。

重点检查：上升普通后日谈是异地联系、理想后日谈共同出发；创业普通后日谈明确经过时间才上线。高信任四章保留恋爱发展，但承诺在角色结局兑现；低信任无越级亲密。夏章带回纸带与冒险中止的实际对白一致；撤离/未知另由自动路径与旧档覆盖。真结局门遵循四季交界和双方邀请，返回线邮件保留未证实性质。镜面、银铃和水晶耳坠没有混淆。

## 基础交互与画面

- 存读档：自然状态 3→4→读回 3；五个手动槽与自动存档恢复均成功。
- 回滚、历史可见文本与滚动、快进停在菜单、零输入自动推进、文字/自动速度拖动、Esc/返回、窗口/全屏均实际操作。
- 读取、覆盖、回主菜单、退出四类中文确认均检查；保存缩略图比例与六槽、六选项均正常。
- 9 张新增图片均在实际剧情中显示。独立 GPT-6.1 Sol 美术审查见 `../art/native-review.md`，无人物身份、透明边缘或对话框遮脸的阻断问题。

原生发现而自动断言原先未覆盖的 slider 溢出、标题折行、Esc 导航、历史 viewport 零宽、自动播放默认字段错误均已修复并复查；Pi 针对真实布局与零输入自动推进增加回归。历史截图 `history.png` 与 `settings-before.png` 是修复前证据，最终状态以 `history-after.png` 和 `settings-after.png` 为准。

## 限制

仅在上述 Apple Silicon Mac 实测。未公证；不声称 Intel Mac 或其他操作系统实机通过。两项非阻断美术意见保留：列车人物镜头尺度略有差异；镜中文字比叙述中的“浅得几乎看不清”更明亮。它们不影响身份辨认、剧情或操作。
