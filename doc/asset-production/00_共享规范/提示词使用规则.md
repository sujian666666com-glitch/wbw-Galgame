# 提示词使用规则

## 参考图顺序

1. 若素材存在“上游输出路径”，已验收的上游母版必须作为第一张参考图。
2. 身份或建筑母版。
3. 同角色当前透明立绘，或同地点当前运行时背景。
4. 对应剧情 CG，用于补充情绪、道具和光线。
5. 仅在需要时加入城市空间或相邻地点参考。

## 生成与编辑边界

- 文件标注“同源编辑”时，必须使用已有图片编辑，不得从纯文字重新生成。
- 提示词中的英文素材 ID 是文件身份，不应作为画面文字出现。
- 文档、姓名卡和档案中的可读中文统一在后期 UI 中添加；生成图只表现纸张、印章、签名结构和留白。
- 角色地图头像标注 `DERIVED`，只允许裁切和轻度修整，禁止重新生成人脸。
- `EVENT_GRAPH_DEPENDENT` 项目中的提示词只是构图草案，事件目标、地点和情绪确认后必须复核。

## 通用负面约束

```text
no watermark, no logo, no legible AI text, no extra fingers, no duplicate limbs,
no cropped head or feet, no identity drift, no costume redesign, no unrelated characters,
no modern skyscraper city unless explicitly requested, no sexualized school setting,
no baked dialogue UI, no embedded map markers unless explicitly requested
```

## 文件命名

- 背景：`bg_<location>_<state>.png`
- 立绘：`角色英文名_表情或服装.png`
- CG：`cg_<story-unit>.png`
- UI：`ui_<group>_<item>.png`
- 透明特效：`vfx_<effect>.png`
