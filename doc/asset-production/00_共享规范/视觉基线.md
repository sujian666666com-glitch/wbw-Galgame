# 视觉基线

## 统一风格

- 高完成度、半写实动漫视觉小说风格，柔和但可信的材质与电影光照。
- 人物身份以现有合影、透明立绘和个人 CG 为准，不根据文字重新设计脸、发型、年龄或服装主色。
- 实际参考图显示的角色色系为：Dana 粉色、Luna 深青与藏蓝、Irene 象牙白与牛仔蓝、Ruby 银发与灰紫。若旧文档中的颜色描述冲突，以图片身份母版为准。
- 樱镜町建筑统一为临海旧城：木构、浅色灰泥、窄街、低层建筑、可见海面和缓坡；不要变成现代大都市或传统古代城镇。

## 背景构图契约

- 运行时尺寸：`1920×1080`。
- 背景不包含主要人物，不包含可读文字、Logo 或水印。
- 中央与左右人物站位区域避免大面积高对比物体。
- 画面下方约 28% 保持相对安静，避免与对话框争夺信息。
- 同地点时间或天气变体必须保留原建筑、镜头、透视、窗门数量和地标位置。

## 立绘契约

- 全身或接近全身，头顶和鞋底完整，手指不被裁切。
- 先输出纯色色键背景源图，再去背为 RGBA PNG。
- 运行时显示高度不超过 `1024 px`，四角透明。
- 表情变化只改变情绪、眼神、嘴形和小幅肢体语言；不要同时改变年龄、身材和服装结构。

## CG 契约

- `1920×1080`，一个明确的情绪节拍，不做无焦点的多人站桩照。
- 保留对话框安全区，但关键手部、道具与面部不能被下方 UI 遮挡。
- 同一角色跨 CG 必须核对发型、饰品、服装和身高关系。

## UI 与透明素材契约

- 图标以透明 PNG 交付；同一套图标统一线宽、投影和视觉重量。
- 地图、头像、事件标记、锁定状态和光效彼此独立。
- 不为清晨、黄昏、深夜预渲染整套背景；优先通过运行时调色和遮罩实现。
