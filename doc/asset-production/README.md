# 《樱镜町》素材生产规格

本目录服务于“城市日程探索型视觉小说”重构。它只描述素材生产，不代表素材已经生成，也不改变当前 Ren'Py 运行时。

## 使用顺序

1. 先读 `00_共享规范/视觉基线.md` 与 `00_共享规范/提示词使用规则.md`。
2. 在 `MANIFEST.md` 中选择一个素材 ID。
3. 打开对应分级目录，核对状态、输出规格、提示词和参考图片。
4. 生成时必须按参考图片列出的顺序提供参考；同一地点的时间变体优先使用图像编辑，不重新设计建筑。
5. 按 [OUTPUT_PATHS.md](/Users/ik/Desktop/02_学习与资料/game/my-renpy-game/doc/asset-production/OUTPUT_PATHS.md) 保存源图和运行时文件：源图进入 `image/续篇/`，验收后的运行时文件进入 `game/images/sequel/`。

## 状态含义

- `READY`：故事事实与构图已经足够明确，可以制作。
- `LAYOUT_DEPENDENT`：提示词已准备好，但必须先确认城市节点坐标。
- `EVENT_GRAPH_DEPENDENT`：只保留概念提示词；人物自由事件图确认后才能定稿。
- `DERIVED`：从现有素材裁切或编辑，不应重新生成人物身份。

`MANIFEST.md` 中的“组”代表一次需要保持视觉一致性的生产批次；组内每个实际交付文件仍在对应规格中逐项命名，不能只保存一张未切分的拼图。

## 范围边界

- 五个时段不等于每个地点制作五张背景。高频地点采用白天／夜晚母版，清晨、黄昏、深夜通过调色和光照实现。
- 地图头像、事件光点、锁定状态必须是独立图层，不烘焙进城市地图。
- 普通交谈使用立绘，不为每次对话制作 CG。
- `EVENT_GRAPH_DEPENDENT` 素材不得先生成，以免美术反过来锁死尚未确认的剧情。
